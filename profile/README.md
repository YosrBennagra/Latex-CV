# Profile Knowledge Base

Organized, human-readable views of the master profile for **Yosr Ben Nagra**.

> **IMPORTANT — source of truth**
> `data_profile.json` (repo root) is the single source of truth for all personal
> data. The files in this folder are *organized views* of that data, split by
> topic so they are easy to browse, tailor from, and keep managed.
> **Workflow:** update `data_profile.json` first, then sync the affected file(s)
> here. Never add anything here that is not in (or added to) the JSON.

## Files

| File | Contents | Use it when... |
|------|----------|----------------|
| `job_titles.md` | All job titles qualified for (EN + FR), grouped by fit strength | Deciding which roles to apply to / which CV variant to use |
| `skills.md` | Skills inventory by category | Filling the Skills section of a CV |
| `technologies.md` | Full technology list with *where it was used* (evidence) | Answering "have you used X?" honestly; ATS keyword matching |
| `experience.md` | Work experience and internships (EN + FR summaries) | Filling the Experience section |
| `projects.md` | Personal / founder projects catalog | Filling the Projects section |
| `education_certifications.md` | Degrees and certificates | Filling Education / Certifications sections |
| `languages_soft_skills.md` | Spoken languages and evidenced soft skills | Languages section, Key Strengths bullets |
| `ats_keywords.md` | ATS keyword bank per target role | Tailoring a CV to pass a specific ATS scan |

## Rules (from CLAUDE.md)

1. Never fabricate experience, skills, companies, or dates.
2. Keep EN and FR content synchronized.
3. ASCII text by default — no accents unless requested.
4. When a job posting requires a skill not listed here, ask the user first —
   do not silently add it.
