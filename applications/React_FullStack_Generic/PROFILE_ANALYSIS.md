## Interview Prep - React Specific

### React Hooks Questions

**Q: Explain useMemo vs useCallback**
```
A: useMemo memoizes a computed value, useCallback memoizes a function.
Use useMemo for expensive calculations, useCallback to prevent child 
re-renders when passing callbacks as props. Both depend on dependency array.
```

**Q: When to use Redux vs Context API?**
```
A: Context API for simple, localized state (theme, auth, small apps).
Redux Toolkit for complex state with many actions, need for devtools,
middleware, time-travel debugging. I've used both - Redux Toolkit for 
large apps, Context for smaller state management needs.
```

**Q: Describe your testing approach**
```
A: Three-layer approach:
1. Unit tests (Jest + RTL) for components and hooks
2. Integration tests for feature flows
3. E2E tests (Cypress) for critical user journeys
Aim for 80%+ coverage on business logic.
```

### Next.js Questions

**Q: SSR vs SSG vs CSR - when to use each?**
```
A: SSR for dynamic, personalized content (dashboards, user-specific pages).
SSG for static content (blogs, marketing pages) - best performance.
CSR for highly interactive apps. Use ISR for best of both worlds.
```

### State Management

**Q: Why Redux Toolkit over plain Redux?**
```
A: Less boilerplate, built-in Immer for immutability, createSlice API,
RTK Query for data fetching, better DevTools. More maintainable codebase.
```
